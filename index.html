Workflow
Free mode: drag any corner dot. ←/→ (or ↑/↓) previous/next region. Alt+arrows nudge the last-used corner 1px (Alt+Shift = 10px).
Keys 1–4: zoom onto TL/TR/BR/BL, click the true corner; it advances to the next corner, after BL it returns to free mode.
Put corners on the outer edge of the print paper (include a white print border, exclude the sleeve/page).
R rotates the output, Enter = OK & next, N adds a region, X deletes, F refines this region.
Run cropper
Output folder (one subfolder per source folder when photos come from several)
